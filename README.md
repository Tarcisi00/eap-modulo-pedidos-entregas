## Objetivo

Este repositório reúne a Estrutura Analítica do Projeto (EAP) do **Módulo de Pedidos e Entregas**. A EAP divide o escopo do módulo em entregas organizadas em 3 níveis, para apoiar o planejamento, a estimativa e o acompanhamento do projeto.
